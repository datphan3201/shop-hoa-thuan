# Acceptance evidence

backup, secret, session cookie, PIN hoặc installer cache. Evidence Windows/điện thoại thật được
thêm sau khi chạy checklist và phải ghi commit, thời gian, môi trường, kết quả PASS/FAIL/BLOCKED.
